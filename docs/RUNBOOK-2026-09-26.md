# 运行手册：本轮三组实验（按顺序跑）

预注册见 [PREREG-2026-09-26.md](PREREG-2026-09-26.md)。**跑之前确认预注册已提交**（`git log --oneline -3`），运行期间不要改仓库里被跟踪的文件，否则结果里记录的 `git_dirty` 会是 True。

## 0. 环境与空间

- 依赖：`requirements.txt`（sahi 0.12.7、ultralytics ≥ 8.3、pycocotools）。torch 按 CUDA 版本另装。
- 权重：`yolo11s.pt`、`yolo11s-obb.pt` 首次运行时由 ultralytics 自动下载（各约 20 MB）。
- 磁盘：VisDrone val 约 80 MB；DOTAv1.zip 约 2 GB，只需解出 `images/val` 和 `labels/val`。**解压前确认至少有 3 GB 空闲**。
- 先跑测试：`python -m pytest -q`，应全部通过。

## 1. VisDrone（约 20 分钟，4070 Laptop 估计）

```bash
python scripts/prepare_data.py
python scripts/run_eval.py cache
python scripts/holdout_theta.py --dataset visdrone
python scripts/apparent_size.py visdrone
python scripts/strong_baselines.py run --dataset visdrone
python scripts/strong_baselines.py eval --dataset visdrone
```

说明：
- `cache` 会重写 `results/cache.pkl`（已被忽略，不进 git）。原报告的 sweep.csv 不受影响。
- `holdout_theta` 纯离线，输出 `results/holdout_theta.csv`。
- `strong_baselines run` 每张图跑 12 个方法，是本轮最慢的一步。先用 `--limit 20` 试跑，确认没报错再跑全量。

## 2. DOTA 换检测器（约 30–40 分钟）

```bash
python scripts/prepare_data.py --dataset dota15
python scripts/run_eval.py cache --dataset dota15 --weights yolo11s-obb.pt --imgsz 1024 --slice-size 1024
python scripts/run_eval.py sim --dataset dota15
python scripts/coverage.py dota15
python scripts/holdout_theta.py --dataset dota15
python scripts/apparent_size.py dota15
python scripts/strong_baselines.py run --dataset dota15 --weights yolo11s-obb.pt --imgsz 1024 --slice-size 1024 --full-sizes 1024,2048,3072 --sahi-sizes 1024,1536,2048 --glance-ths 0.5,0.9
python scripts/strong_baselines.py eval --dataset dota15 --op 0.9
```

说明：
- 如果已经有 `datasets/DOTAv1/images/val`，`prepare_data` 只会多生成一个 `coco_eval_dota15.json`，不会重新下载，也不会覆盖原来的 3 类真值。
- 结果全部写进 `results/dota15/`，不碰原来的 `results/dota/`。
- full@3072 在 4000 像素的大图上显存占用最高。如果出现 OOM，把 `--full-sizes` 改成 `1024,2048` 重跑，并在结果里写明。
