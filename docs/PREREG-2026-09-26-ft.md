# 预注册附录：VisDrone 微调检测器后重做实验 A 与留出 θ（2026-09-26）

本文件和 `scripts/train_visdrone.py` 一起提交后才开始训练，提交时间以 git 记录为准。之后不再修改本文件。

## 为什么做

实验 A（`docs/RESULTS-A-visdrone-2026-09-26.md`）用的是零训练 COCO 检测器，结果是高分辨率整图推理同时支配 SAHI 和 Glance-SAHI。它的"结论边界"里写了：微调过的检测器，结论可能不同。评委也一定会问"为什么不训练"。这一轮把检测器换成在 VisDrone 训练集上微调过的版本，重做同一套对照。

## 设置（写死）

- **数据**：VisDrone2019-DET-train，按文件名 md5 取模 20，留出 5% 做 mini-val，只用来选 best.pt。VisDrone val 的 548 张不参与训练，也不参与选模型。
- **样本**：每张训练图生成两份。一份是整图缩到长边 640，对应扫视和整图推理的尺度；一份是原分辨率 640×640 裁块，对应 SAHI 切片的尺度，80% 的概率以某个目标为中心。忽略区域先抹成灰色 114。
- **类别**：2 类，0 person（pedestrian、people），1 vehicle（car、van、truck、bus）。与评测口径相同。
- **训练**：从 `yolo11s.pt`（COCO）开始，imgsz 640，batch 16，时间预算 1.2 小时，其余用 Ultralytics 默认值，种子 0。
- **评测**：数据集名 `visdrone_ft`，与实验 A 用同一套脚本、同一组方法（full@640–2560、sahi@512–1024、glance@0.9/0.99），在同一台 4070 上跑。然后按原预注册实验 C 的规则跑 `holdout_theta`。训练结束后、评测开始前，不再改任何代码。

## 预测

- **F1（微调有效）**：在 sahi@512 和 full@1920 两个方法上，微调检测器的 AP 都比 COCO 检测器高至少 3 点（COCO 分别是 28.52 和 35.13）。
- **F2（整图仍支配）**：微调后，高分辨率整图推理仍然在墙钟上支配 glance@0.9（判定规则同原预注册实验 A）。主观概率约 70%。理由是整图推理的优势（没有切缝、调用一次）与检测器无关。如果训练用的裁块让切片尺度的检测明显变强，这条可能不成立。
- **F3（Glance 相对 SAHI 的结论不变）**：glance@0.9 相对 sahi@512 的 ΔAP 下界 > −0.6，切片节省在 15%–30% 之间。
- **F4（留出 θ）**：按实验 C 的规则，调参集上能选出 θ*，并且留出集上的保住比例 ≥ 95%。

## 判定后怎么写

- 不管哪条不成立，都照实写进结果文件，不补跑、不换规则。
- 如果 F2 成立，主文的 VisDrone 部分就定为：Glance-SAHI 是对 SAHI 的一个免训练改进，但在 VisDrone 这种图不大的场景，整图高分辨率推理更好。Glance-SAHI 适用于必须切片的场景，由 DOTA（实验 B）来检验。
